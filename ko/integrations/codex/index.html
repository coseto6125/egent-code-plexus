Codex CLI

네 가지 경로, 하나의 그래프.

Codex CLI에는 구조 질의를 써야 할 때를 가르치는 스킬을 설치합니다. 질의 자체에 닿는 경로는 두 가지로, ~/.codex/config.toml을 통한 MCP 또는 네이티브 도구 스캐폴드입니다.

설치

  • ecp admin codex install skills
  • ecp admin codex install native-tools

설치 확인

  • ecp admin codex status

알아둘 점

native-tools가 만들어내는 것은 openai/codex 포크용 스캐폴드이지 배포된 바이너리에 대한 패치가 아닙니다. Codex를 직접 빌드하지 않는다면 실제로 동작하는 쪽은 MCP 경로입니다.

이 페이지의 모든 명령은 ecp 0.10.1 바이너리의 help 출력에서 그대로 가져왔습니다.
