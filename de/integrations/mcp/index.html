Any MCP host

Vier Kanäle, ein Graph.

ecp admin mcp serve ist ein stdio-JSON-RPC-MCP-Server mit 20 Tools; jeder Host, der MCP spricht, kann damit den Graphen abfragen. Zeige den Host auf das Binary, und es funktioniert ohne Registrierung auf ecp-Seite.

Konfiguration

{
  "mcpServers": {
    "ecp": { "command": "ecp", "args": ["admin", "mcp", "serve"] }
  }
}
  • Cursor — ~/.cursor/mcp.json
  • Windsurf — ~/.codeium/windsurf/mcp_config.json
  • Cline / Roo Code — cline_mcp_settings.json
  • Copilot — VS Code settings.json

Installation prüfen

  • ecp admin mcp tools

Gut zu wissen

Die automatischen Installer für Cursor, Windsurf, Cline / Roo Code und Copilot sind noch nicht geschrieben – sie geben einen Platzhalter aus, statt eine Config zu editieren. Diese Hosts nehmen das JSON oben von Hand, und genau deshalb steht es hier, statt hinter einem Befehl zu verschwinden.

Jeder Befehl auf dieser Seite stammt aus der eigenen Help-Ausgabe des ausgelieferten Binarys, Stand ecp 0.13.0.
