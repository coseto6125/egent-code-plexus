Claude Code

Quatre canaux, un seul graphe.

Claude Code accède à ecp par trois canaux indépendants : des hooks settings.json qui réindexent au fil des changements du dépôt, des skills qui disent au modèle quand une requête de graphe bat un grep, et un serveur MCP enregistré via claude mcp add-json. Installez ce que vous voulez ; rien ici ne dépend du reste.

Installation

  • ecp admin claude install hooks
  • ecp admin claude install skills
  • ecp admin claude install mcp-server

Vérifier que c'est en place

  • ecp admin claude status

Bon à savoir

Le skill pèse plus lourd que les outils. Un modèle qui peut appeler ecp mais n'a aucune règle sur quand l'appeler dégaine quand même grep en premier. Une installation partielle est normale, et ecp admin claude status affiche les composants réellement en place.

Chaque commande de cette page vient de la sortie d'aide du binaire livré, sur ecp 0.12.1.
