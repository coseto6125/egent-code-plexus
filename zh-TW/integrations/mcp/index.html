Any MCP host

四種通道，同一張圖。

ecp admin mcp serve 是一個 stdio JSON-RPC 的 MCP server，對外開 20 個工具，所以任何講 MCP 的 host 都叫得動這張圖。把 host 指向這個執行檔即可，ecp 這側不需要另外註冊。

設定內容

{
  "mcpServers": {
    "ecp": { "command": "ecp", "args": ["admin", "mcp", "serve"] }
  }
}
  • Cursor — ~/.cursor/mcp.json
  • Windsurf — ~/.codeium/windsurf/mcp_config.json
  • Cline / Roo Code — cline_mcp_settings.json
  • Copilot — VS Code settings.json

確認裝好了

  • ecp admin mcp tools

要知道的事

Cursor、Windsurf、Cline / Roo Code、Copilot 的自動安裝器還沒寫，執行後只會印一行佔位訊息，不會真的改設定檔。這幾家目前要自己貼上面那段 JSON，所以這裡直接把它印出來，而不是藏在一個指令後面。

本頁每一條指令都來自 ecp 0.12.1 執行檔本身的 help 輸出。
