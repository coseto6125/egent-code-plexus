Claude Code

Quatro canais, um grafo.

O Claude Code lê o ecp por três canais independentes: hooks no settings.json que reindexam conforme o repositório avança, pacotes de skill que dizem ao modelo quando uma consulta ao grafo supera um grep, e um servidor MCP registrado via claude mcp add-json. Instale o que quiser; nada aqui depende do resto.

Instalação

  • ecp admin claude install hooks
  • ecp admin claude install skills
  • ecp admin claude install mcp-server

Confira se aplicou

  • ecp admin claude status

Vale saber

A skill pesa mais que as ferramentas. Um modelo que pode chamar o ecp mas não tem regra de quando chamá-lo ainda recorre ao grep primeiro. Uma instalação parcial é normal, e ecp admin claude status mostra quais componentes estão de fato instalados.

Todos os comandos desta página vêm da saída de help do próprio binário distribuído, no ecp 0.12.1.
