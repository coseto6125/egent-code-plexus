네 가지 경로, 하나의 그래프.

에이전트는 네 가지 경로 중 하나로 ecp에 연결됩니다. 인덱스를 따뜻하게 유지하는 설정 훅, 텍스트 검색보다 구조 질의가 나은 순간을 모델에게 알려주는 스킬, 질의를 도구로 노출하는 MCP 서버, 그리고 호스트 전용 플러그인입니다. 대부분의 호스트는 여러 개를 함께 쓸 수 있고, 각각 따로 설치합니다.
