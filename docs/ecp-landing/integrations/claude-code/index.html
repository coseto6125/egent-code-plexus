Claude Code

Four channels, one graph.

Claude Code reads ecp through three independent channels: settings.json hooks that reindex as the repository moves, skill packs that tell the model when a graph query beats a grep, and an MCP server registered through claude mcp add-json. Install what you want; nothing here depends on the rest.

Install

  • ecp admin claude install hooks
  • ecp admin claude install skills
  • ecp admin claude install mcp-server

Check it landed

  • ecp admin claude status

Worth knowing

The skill carries more weight than the tools. A model that can call ecp but has no rule for when to call it still reaches for grep first. A partial install is normal, and ecp admin claude status prints which components are actually in place.

Every command on this page comes from the shipped binary's own help output, on ecp 0.11.0.
