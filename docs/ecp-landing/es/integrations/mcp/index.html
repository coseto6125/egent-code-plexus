Any MCP host

Cuatro canales, un solo grafo.

ecp admin mcp serve es un servidor MCP JSON-RPC por stdio que expone 20 herramientas, así que cualquier host que hable MCP puede consultar el grafo. Basta con apuntar el host al binario; del lado de ecp no hace falta registrar nada.

Configuración

{
  "mcpServers": {
    "ecp": { "command": "ecp", "args": ["admin", "mcp", "serve"] }
  }
}
  • Cursor — ~/.cursor/mcp.json
  • Windsurf — ~/.codeium/windsurf/mcp_config.json
  • Cline / Roo Code — cline_mcp_settings.json
  • Copilot — VS Code settings.json

Comprobar que quedó instalado

  • ecp admin mcp tools

Conviene saber

Los instaladores automáticos para Cursor, Windsurf, Cline / Roo Code y Copilot todavía no están escritos: imprimen un marcador de posición en lugar de editar una configuración. Esos hosts requieren pegar el JSON de arriba a mano, y por eso aparece aquí en lugar de esconderse detrás de un comando.

Cada comando de esta página proviene de la ayuda del propio binario, en ecp 0.10.1.
