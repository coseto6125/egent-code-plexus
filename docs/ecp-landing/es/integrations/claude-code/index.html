Claude Code

Cuatro canales, un solo grafo.

Claude Code lee ecp por tres canales independientes: hooks en settings.json que reindexan según se mueve el repositorio, packs de skills que le dicen al modelo cuándo una consulta al grafo gana a un grep, y un servidor MCP registrado mediante claude mcp add-json. Instala lo que quieras; ninguno depende de los demás.

Instalación

  • ecp admin claude install hooks
  • ecp admin claude install skills
  • ecp admin claude install mcp-server

Comprobar que quedó instalado

  • ecp admin claude status

Conviene saber

La skill pesa más que las herramientas. Un modelo que puede llamar a ecp pero no tiene una regla sobre cuándo llamarlo sigue tirando de grep primero. Una instalación parcial es normal, y ecp admin claude status imprime qué componentes están realmente puestos.

Cada comando de esta página proviene de la ayuda del propio binario, en ecp 0.11.0.
