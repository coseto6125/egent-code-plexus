Orca

Quatre canaux, un seul graphe.

Orca installe ecp comme plugin : ajoutez le dépôt comme source de marketplace, puis installez ECP Code Graph depuis la liste. Chaque worktree créé par Orca est indexé en arrière-plan, et un panneau met index, impact et summary à un clic.

Installation

  • https://github.com/coseto6125/ecp-orca-plugin.git

Vérifier que c'est en place

  • ecp summary

Bon à savoir

Le plugin n'installe pas le binaire ecp, et il tourne sur la machine cliente d'Orca même quand le worktree vit sur une autre. Installez ecp là où se trouve le code.

Chaque commande de cette page vient de la sortie d'aide du binaire livré, sur ecp 0.10.2.
