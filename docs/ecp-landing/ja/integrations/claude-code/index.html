Claude Code

4 つの経路、1 つのグラフ。

Claude Code は 3 つの独立した経路で ecp を読みます。リポジトリの変化に合わせて再インデックスする settings.json のフック、grep よりグラフクエリが適する場面をモデルに教えるスキルパック、そして claude mcp add-json で登録する MCP サーバーです。必要なものだけ入れられ、互いに依存しません。

インストール

  • ecp admin claude install hooks
  • ecp admin claude install skills
  • ecp admin claude install mcp-server

導入を確認する

  • ecp admin claude status

知っておくこと

ツールそのものよりスキルの方が効きます。ecp を呼べるモデルでも、いつ呼ぶかの規則がなければ最初に手が伸びるのは grep です。一部だけ導入されている状態は普通で、ecp admin claude status が実際に入っている構成要素を一覧します。

このページのコマンドはすべて、ecp 0.9.3 のバイナリ自身のヘルプ出力から取っています。
